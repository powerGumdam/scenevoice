# Whisper 추론 성능 벤치마크

Apple Silicon 환경에서 STT 처리 속도를 비교하여, SceneVoice의
음성 인식 단계를 로컬 추론으로 처리할 수 있는지 검증한다.

## 측정 환경

- 기기: MacBook Pro / M5 / RAM 16 GB
- OS: macOS Tahoe
- 입력: 60초 오디오 (16kHz, 모노, WAV)
- 원본: 1920x1080 HEVC 영상에서 FFmpeg으로 추출
- 모델: whisper-small
- 측정: `time` 명령의 total 값, 모델 다운로드 이후 2회차 실행 기준

## 결과

| 방식 | 모델 크기 | 처리 시간 | CPU 대비 | 실시간 배속 |
|---|---|---|---|---|
| CPU (openai-whisper) | 461MB | 145.8초 | 1배 | 0.41배 |
| MLX (FP16) | 459MB | 3.75초 | 38.9배 | 16.0배 |
| MLX (INT4 양자화) | 187MB | 3.19초 | 45.7배 | 18.8배 |

10분 영상 기준 환산: CPU 24분 20초 → MLX INT4 32초

## 분석

### GPU 활용의 효과

CPU 버전은 `FP16 is not supported on CPU` 경고와 함께 FP32로 연산하며
CPU 사용률 191%를 기록했다. 코어 2개 수준만 사용하고 GPU는 유휴 상태였다.

MLX 버전은 CPU 사용률이 49%로 떨어졌다. 연산이 GPU로 이동했기 때문이며,
`time`은 GPU 점유 시간을 계측하지 않으므로 수치가 낮게 나온다.

Apple Silicon은 CPU와 GPU가 통합 메모리를 공유하므로 장치 간 데이터
복사 비용이 없다. 이것이 39배라는 차이의 근본 원인이다.

### 양자화의 효과

INT4 양자화는 처리 시간을 15% 단축(3.75초 → 3.19초)한 반면,
모델 크기는 59% 감소(459MB → 187MB)했다.

속도 이득이 제한적인 이유는 두 가지로 판단된다.
첫째, small 모델은 규모가 작아 메모리 대역폭이 병목이 아니다.
둘째, 3초 남짓한 처리 시간에는 오디오 로딩과 전처리 등 양자화로
줄일 수 없는 고정 비용이 포함되어 있다.

모델 크기 감소는 서버 메모리에 동시 적재 가능한 모델 수를 결정하므로,
동시 처리량 측면에서 별도의 가치를 가진다.

## 한계

측정에 사용한 오디오 구간이 배경음악 위주여서 두 모델 모두 환각
(같은 문장 반복)을 보였다. 따라서 이 실험은 처리 속도만 유효하며,
인식 정확도에 대한 결론은 도출할 수 없다.

정확도 비교는 사람의 발화가 포함된 구간으로 별도 측정이 필요하다.
